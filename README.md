# 🏥 Hospital Appointment

A complete web platform for managing hospital appointments.

## 📌 Project Overview

This application allows patients to book and manage appointments
with doctors while providing dedicated management spaces for
doctors, managers and administrators.

## 👤 Patient
- Registration and authentication
- Browse medical specialties
- Browse doctors
- View doctor availability
- Book appointments
- Track appointments
- Cancel appointments

## 👨‍⚕️ Doctor
- Personal dashboard
- Manage profile
- Manage availability
- View appointments
- Confirm or cancel appointments

## 👨‍💼 Manager
- Dashboard and statistics
- Manage doctors
- Manage patients
- Manage appointments
- Track appointment statuses

## 🔐 Administrator
- Manage doctor requests
- Manage specialties
- Manage users and roles
- Manage notifications

## 🛠️ Technologies

- React.js
- Laravel
- PHP
- MySQL
- REST API
- Laravel Sanctum
- Axios
- React Router
- Git / GitHub

## 🏗️ Architecture

Frontend: React.js  
Backend: Laravel API  
Database: MySQL
